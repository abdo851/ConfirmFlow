# Development Rules (Summary)

Full rules: [DEVELOPMENT_RULES.md](../../DEVELOPMENT_RULES.md) at project root.

## Quick Reference

- Migrations for all schema changes
- Adapters for all external integrations
- No production direct edits or data deletion
- No secrets in code
- Stop and ask when requirements are unclear
- Complete and review each milestone before proceeding

## Milestone Discipline

M0 is foundation only. Do not implement Shopify, Meta, confirmation services, dashboard features, or billing until explicitly approved in a future milestone spec.
